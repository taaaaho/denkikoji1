# denkikoji1

iOSアプリ「電工一種 学科 合格予測（非公式）」の公開情報（サポート・プライバシーポリシー・利用規約）を管理するリポジトリです。GitHub Pages（`main` ブランチの `/docs`）で公開しています。

- サポート: https://taaaaho.github.io/denkikoji1/
- プライバシーポリシー: https://taaaaho.github.io/denkikoji1/privacy.html
- 利用規約: https://taaaaho.github.io/denkikoji1/terms.html

ページの文言は `scripts/build_pages.py` で管理しています。編集後に `python3 scripts/build_pages.py` を実行してください。

本アプリは個人開発の非公式アプリであり、一般財団法人電気技術者試験センターその他の団体とは提携・協力・監修関係はありません。

ソースコードは非公開リポジトリ（`denkikoji1-code`）で管理しています。
